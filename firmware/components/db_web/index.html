Der DeckConnector verbindet sich selbst mit Companion. Ohne Port nimmt er 16622. Eine ws:// oder wss:// Adresse geht über den WebSocket-Port von Companion (16623) oder einen Proxy davor. Leer lassen, wenn Companion den DeckConnector als Network Dock findet.
