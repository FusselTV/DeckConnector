## In the browser

The [flasher](/flash/) writes the latest stable [release](/docs/updates#releases). It needs Chrome or Edge on a computer.

<Ports />

After flashing, the flasher can join your Wi-Fi over the same cable. Everything else follows in the [web setup](/docs/first-setup).

The flasher writes only the main chip. The Wi-Fi chip gets its firmware as a normal [update](/docs/updates).

Something went wrong? See [Flashing problems](/docs/flash-troubleshooting).

## With esptool

Use [esptool](https://docs.espressif.com/projects/esptool/) 5 or newer with the files from a [release](/docs/updates#releases).

<Tabs items={['Full install', 'Update']}>
<Tab value="Full install">

```bash
esptool --chip esp32p4 -p /dev/ttyACM0 erase-flash
esptool --chip esp32p4 -p /dev/ttyACM0 -b 921600 write-flash 0x0 deckconnector-factory.bin
```

</Tab>
<Tab value="Update">

```bash
esptool --chip esp32p4 -p /dev/ttyACM0 -b 921600 write-flash 0xf000 ota_data_initial.bin 0x20000 deckconnector.bin
```

</Tab>
</Tabs>

On Windows the port is `COM3` or similar, on macOS `/dev/cu.*`.
