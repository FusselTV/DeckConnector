The connector uses Wi-Fi and Ethernet (LAN) at the same time, each with its own address. With both, connections go over the cable and Wi-Fi is the backup.

## Failover

<Failover />

The connector announces its name on one network at a time. That is the LAN, or Wi-Fi while the LAN has no address or counts as dead.

## Wi-Fi

- A hidden network is not in the list, but you can type its name.
- The connector tests a new network first and keeps it only when it gets an address there. Otherwise the old one comes back.
- **Access points** locks the connector to one access point. By default it takes the strongest and roams.
- **Backup Wi-Fi** is a second network. The connector joins it when the first one is gone, and goes back by itself. On the backup it always takes its address over DHCP.

## Fixed address

LAN and Wi-Fi each take DHCP or a fixed address. A fixed address needs IP and netmask, the gateway is optional and must be in the same network. `10.0.0.5/24` works in the IP field. Saving restarts the connector, and the web UI shows where to find it ([demo](/demo/#network)).

On a deck with dials, the [deck menu](/docs/first-setup#on-the-deck-alone) sets a fixed LAN address too.

## Names

The connector's name in the network is `<name>.local`, for example `deckconnector-a1b2c3.local`.

| mDNS service | What |
|---|---|
| `_deckconnector-api._tcp` | Web UI and API |
| `_elg._tcp` | The Network Dock, only while a deck is plugged in |
| `_companion-satellite._tcp`, `_comp-sat-app._tcp` | Lists the connector under **Surfaces › Discover** in Companion |

## Ports

- **80 and 443** on the connector: web UI and API, over HTTP and HTTPS.
- **5343 and 5344** on the connector: the Network Dock, for Companion and the Elgato app. Deck 2 uses 5345 and 5346, and so on.
- **16622** on the Companion computer: Satellite. **16623** for a `ws://` address.

## Internet

The connector talks to the internet only in these cases. Each one shows the IP address of your network to that server.

- **Time.** `pool.ntp.org`, only when your router names no time server and you set none under **Network**.
- **Update check.** GitHub, only when you click **Check for updates** under **Firmware**, or while the [Home Assistant](/docs/home-assistant) firmware entity is on.
- **Update by URL.** The address you give, and GitHub for a release.
- **Your servers.** The Companion, Satellite and own servers you set.
- **Matter.** Nothing from the connector. The Home app, Google Home or Alexa you pair it with can send the deck's names and presses to Apple, Google or Amazon.

It sends no usage data and no crash reports.
