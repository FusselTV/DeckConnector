title: Sources
description: Several programs connected at once, and how to pick the one that draws.
---

A source is a program that draws on the deck: Companion, the Elgato app or your own server. Up to 2 servers and 4 Network Dock sources connect at once, in any mix.

One source is **active**. It draws and gets the input. The others stay connected. Companion and the Elgato app keep drawing into their own picture in the background, so a switch shows it at once. A server draws again after the switch.

## Switching

<HostSwitch />

- **On the deck.** On the home screen, tap a source, then tap again within 3 s while it says **Switch?**.
- **In the web UI.** Pick a row under **Active source** on the overview ([demo](/demo/#overview)).
- **Over the API.** Set `controller` and `host`, see below.

When no source draws, the deck shows its home screen and says what is missing, for example **Waiting for Companion**.

## When a source goes away

- The first connected source of the same program draws. For Companion, Satellite comes first.
- A server that drew and set a [fallback picture](/docs/own-server#fallback) leaves it on the deck until a server draws again. Between two servers, the servers decide which one draws.
- With no source of that program, the deck shows its home screen.

## Over the API

Two settings pick the source. `controller` is the program, `host` names the entry from `sources` in the status.

| `controller` | Program | `host` |
|---|---|---|
| `companion` | Companion, Satellite or dock | `satellite`, or the computer's IP |
| `app` | The Elgato app | The computer's IP |
| `server` | Your own servers | Empty |

An empty `host` means the first connected source of that program. The change works at once.

```bash
curl -u admin:PASSWORD -H 'X-DeckConnector: 1' -X PUT \
  -d '{"controller": "companion", "host": "satellite"}' http://192.168.1.50/api/config
```
