Die DeckConnector-Integration holt die Platine und jedes Deck daran in [Home Assistant](https://www.home-assistant.io/). Jeder Druck, jedes Loslassen und jede Drehung kommt sofort als Ereignis an. Helligkeit, Bildschirm aus, Wahl des Hosts und Updates steuerst du aus Home Assistant.

## Installieren

Öffne in HACS **Benutzerdefinierte Repositories**, füge dieses Repository als **Integration** hinzu, lade **DeckConnector** herunter und starte Home Assistant neu.

```text
https://github.com/FusselTV/DeckConnector
```

## Einrichten

Home Assistant findet die Platine von selbst und bietet sie unter **Einstellungen › Geräte & Dienste** an. Sonst fügst du dort **DeckConnector** hinzu und gibst die Adresse ein.

Dann wählst du den Weg hinein. **Am Deck bestätigen** fragt am Deck, du tippst zum Annehmen. **Web-Passwort eingeben** geht auch ohne Deck. Home Assistant legt danach seinen eigenen [API-Schlüssel](/de/docs/security#api-schlüssel) auf der Platine an.

## Automationen

Jedes Deck hat ein Ereignis **Bedienung**. Löse darauf aus und prüfe den Ereignistyp in einer Bedingung, zum Beispiel **Taste 3 gedrückt** oder **Drehregler 1 nach rechts gedreht**. Eine Drehung bringt auch `ticks` mit, eine Berührung `x` und `y`.

```yaml
triggers:
  - trigger: state
    entity_id: event.stream_deck_bedienung
    not_to: [unavailable, unknown]
conditions:
  - condition: state
    entity_id: event.stream_deck_bedienung
    attribute: event_type
    state: key_3_press
```

Drücke aus der Weboberfläche oder aus Skripten kommen nie bei Home Assistant an. Home Assistant drückt nie etwas am Deck.

Der Host zeichnet die Tasten. Eine Taste, die auch Companion oder die Elgato-App nutzt, löst beide Aktionen aus.

## Grenzen

- Die Platine muss einfaches HTTP beantworten. Mit **Nur HTTPS** verbindet sich die Integration nicht.

## Entfernen

Lösche die Integration in Home Assistant. Entferne danach ihren Schlüssel `home-assistant-xxxxxxxx` unter **Zugang › API-Schlüssel** auf der Platine.
