<SetupFlow />

1. **Flash.** Connect the board's USB-C port to your computer and open the [flasher](/flash/). It can set Wi-Fi, a password and a name right away. Problems? See [Flashing problems](/docs/flash-troubleshooting).
2. **Plug in.** The deck goes into the board's USB-A port. Power the board over USB-C and it joins the Wi-Fi you set in the flasher's last step. No Wi-Fi set yet? Use the [setup Wi-Fi](/docs/first-setup#over-the-setup-wi-fi). For Ethernet, add a network cable; a PoE port also powers the board. The deck then shows its address.
3. **Set up.** Open the address in a browser and follow the wizard. See [First setup](/docs/first-setup).
4. **Connect.** [Companion](/docs/companion), the [Elgato app](/docs/elgato-app) or your [own server](/docs/own-server). The first one that connects takes the deck.

## The deck menu

While a program draws, hold the first and the last dial for 2 seconds. On a deck without dials, hold the first and the last key. The menu closes after a minute without input.

<DeckMenu />

The deck speaks German or English. The top left key of the menu switches, and the setup sets it too. These docs name the German labels with the English meaning in brackets, for example **Neustart** (restart).
