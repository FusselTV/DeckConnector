---
title: Getting started
description: From a new board to a deck that Companion or the Elgato App controls.
---

<Steps>
<Step>

### Flash the firmware

Connect the board's USB-C port to your computer and open the [flasher](/flash/). It writes the firmware and can set up Wi-Fi, a password and a name right away. See [Flashing](/docs/flashing).

</Step>
<Step>

### Plug in the deck and the network

Plug the Stream Deck into the board's USB-A port. Then connect a LAN cable, ideally from a PoE port. Without PoE, power the board over USB-C.

The deck lights up and shows its address on the touch strip.

</Step>
<Step>

### Run the setup

Open the address in a browser. The setup wizard asks for a name, a password, the network and the program that should control the deck. See [First setup](/docs/first-setup).

</Step>
<Step>

### Connect your program

- [Companion](/docs/companion) over its Satellite API, or as a Network Dock.
- The [Elgato App](/docs/elgato-app) as a Network Dock.
- Your [own server](/docs/own-server) over WebSocket.

The first program that connects takes the deck.

</Step>
</Steps>

## Open the deck menu

While a program draws, hold the first and the last dial together for 2 seconds. On a deck without dials, hold the first and the last key. The menu shows the address, the web password, the network and the list of programs. It closes after a minute without input.

The screens on the deck are in German. Where these docs name a word from the deck, the English meaning follows in brackets, for example **Einrichtung** (setup).
