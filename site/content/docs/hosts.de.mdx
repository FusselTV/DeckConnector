Eine Quelle ist ein Programm, das aufs Deck zeichnet: Companion, die Elgato-App oder dein eigener Server. Bis zu 4 Server und 4 Network-Dock-Quellen sind gleichzeitig verbunden, in jeder Mischung.

Eine Quelle ist **aktiv**. Sie zeichnet und bekommt die Eingaben. Die anderen bleiben verbunden und zeichnen im Hintergrund in ihr eigenes Bild. Nach einem Wechsel zeigt das Deck sofort das Bild der neuen Quelle.

## Wechseln

<HostSwitch lang="de" />

- **Am Deck.** Auf dem Startbildschirm tippst du eine Quelle an und innerhalb von 3 s noch einmal, solange **Wechseln?** dasteht.
- **In der Weboberfläche.** Unter **Aktive Quelle** auf der Übersicht eine andere Zeile wählen ([Demo](/de/demo/#overview)).
- **Über die API.** `controller` und `host` setzen, siehe unten.

Zeichnet keine Quelle, zeigt das Deck seinen Startbildschirm und sagt, was fehlt, zum Beispiel **Warte auf Companion**.

## Wenn eine Quelle wegfällt

- Die erste verbundene Quelle desselben Programms zeichnet. Bei Companion kommt Satellite zuerst.
- Server übernehmen in der Reihenfolge der Liste. Sofort, wenn die Verbindung schließt, innerhalb von 6 s, wenn der Server verstummt.
- Ist keine Quelle dieses Programms da, zeigt das Deck seinen Startbildschirm.

## Über die API

Zwei Einstellungen wählen die Quelle. `controller` ist das Programm, `host` nennt den Eintrag aus `sources` im Status.

| `controller` | Programm | `host` |
|---|---|---|
| `companion` | Companion, Satellite oder Dock | `satellite` oder die IP des Rechners |
| `app` | Die Elgato-App | Die IP des Rechners |
| `server` | Deine eigenen Server | Die Server-URL |

Ist `host` leer, zeichnet die erste verbundene Quelle dieses Programms. Die Änderung wirkt sofort.

```bash
curl -u admin:PASSWORT -H 'X-DeckConnector: 1' -X PUT \
  -d '{"controller": "companion", "host": "satellite"}' http://192.168.1.50/api/config
```
