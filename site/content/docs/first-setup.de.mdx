## Im Browser

Ohne Kabel setzt du zuerst das WLAN im [Flasher](/de/flash/) oder nimmst das [Setup-WLAN](#über-das-setup-wlan). Mit Netzwerkkabel zeigt das Deck seine Adresse und einen QR-Code. Scanne den Code mit dem Handy oder öffne `http://<adresse>/` auf einem Computer im selben Netz.

Der QR-Code meldet diesen Browser einmal ohne Passwort an. Jeder Code gilt 10 Minuten und für eine Anmeldung, bis die Einrichtung fertig ist. Ohne Code meldest du dich als `admin` mit dem Passwort aus dem [Deck-Menü](/de/docs/getting-started#das-deck-menü) an.

Die Einrichtung fragt nach Sprache und Name, deinem eigenen Passwort, dem Netzwerk und dem Programm, das das Deck steuert. Der Name ist auch der Netzwerkname, zum Beispiel `deckconnector-a1b2c3.local`. [Die Einrichtung in der Demo ausprobieren](/de/demo/?setup).

Unter **Firmware › Sicherung** startest du sie später noch einmal.

## Über das Setup-WLAN

Solange die Einrichtung nicht fertig ist und kein Netz da ist, öffnet die Platine eine Minute nach dem Start ein eigenes WLAN. Du kannst es auch im Deck-Menü unter **Setup-WLAN** starten.

Das Deck zeigt Name und Passwort des WLANs, einen QR-Code zum Verbinden, die Adresse und das Web-Passwort. Sobald die Platine in deinem WLAN ist, geht das Setup-WLAN aus und das Deck zeigt die neue Adresse.

<Callout type="warn">
Die Platine kann nur 2,4-GHz-WLAN.
</Callout>

## Nur am Deck

Die Weboberfläche ist optional. Steck ein Netzwerkkabel ein und trag die Adresse vom Deck in der [Elgato-App](/de/docs/elgato-app) oder in [Companion](/de/docs/companion) ein.

Meldet Companion Satellite im Netz an, fragt das Deck **Companion gefunden, verbinden?** Eine Taste verbindet es.

Auf einem Deck mit Drehreglern stellst du im Deck-Menü unter **LAN** eine feste Adresse ein. Ein Drehregler ändert eine Zahl, Drücken springt zum nächsten Feld, dann tippst du auf **Speichern**.

## Werkszustand

- Im Deck-Menü **Neustart** 5 Sekunden halten, dann loslassen.
- Oder auf der Anmeldeseite **Auf Werkszustand zurücksetzen** wählen und zweimal am Deck bestätigen.

Das löscht alle Einstellungen, die API-Schlüssel, die gekoppelten Rechner und ein hochgeladenes Zertifikat.
