The DeckConnector integration brings the board and every deck on it into [Home Assistant](https://www.home-assistant.io/). Each press, release and dial turn arrives at once as an event. You set the brightness, turn the screens off, pick the host and install updates from Home Assistant.

## Install

In HACS, open **Custom repositories**, add this repository as an **Integration**, then download **DeckConnector** and restart Home Assistant.

```text
https://github.com/FusselTV/DeckConnector
```

## Set up

Home Assistant finds the board by itself and offers it under **Settings › Devices & services**. Otherwise add **DeckConnector** there and enter its address.

Then pick a way in. **Confirm on the deck** asks on the deck, and you tap to accept. **Enter the web password** works without a deck. Home Assistant then makes its own [API key](/docs/security#api-keys) on the board.

## Automations

Every deck has one **Controls** event. Trigger on it, then check the event type in a condition, for example **Key 3 pressed** or **Dial 1 turned right**. A dial turn also carries `ticks`, a touch carries `x` and `y`.

```yaml
triggers:
  - trigger: state
    entity_id: event.stream_deck_controls
    not_to: [unavailable, unknown]
conditions:
  - condition: state
    entity_id: event.stream_deck_controls
    attribute: event_type
    state: key_3_press
```

Presses from the web page or a script never reach Home Assistant. Home Assistant never presses anything on the deck.

The host draws the keys. A key that Companion or the Elgato app also uses runs both actions.

## Limits

- The board must answer plain HTTP. With **HTTPS only** on, the integration cannot connect.

## Remove

Delete the integration in Home Assistant. Then remove its key `home-assistant-xxxxxxxx` under **Access › API keys** on the board.
