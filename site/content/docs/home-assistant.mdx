The optional DeckConnector integration brings the connector and every deck on it into [Home Assistant](https://www.home-assistant.io/). You set the brightness, turn the screens off, pick the source, see what each deck shows and update the firmware.

## Install

<Buttons links={[['Install with HACS', 'https://my.home-assistant.io/redirect/hacs_repository/?owner=FusselTV&repository=DeckConnector&category=integration'], ['Add to Home Assistant', 'https://my.home-assistant.io/redirect/config_flow_start/?domain=deckconnector']]} />

1. **Install with HACS** opens the repository in your Home Assistant. Download **DeckConnector**, then restart Home Assistant.
2. Home Assistant finds the connector by itself and offers it under **Settings › Devices & services**. If it does not, use **Add to Home Assistant** and enter the connector's address.

Without HACS, open **Settings › Marketplace**, choose **Add from link** and paste the repository address.

```text
https://github.com/FusselTV/DeckConnector
```

Home Assistant then makes its own [API key](/docs/security#api-keys) on the connector. **Reconfigure** on the integration changes the connector's address and keeps the key.

## What you get

The connector is one device, and each deck is a device behind it. A deck you plug in later appears at once.

These start disabled. Turn them on under the device if you need them:

- **Wi-Fi signal**, **Wi-Fi network** and **Last restart** of the connector.
- **Firmware** update. With it on, the connector asks GitHub for new releases every 6 hours.
- **PIN lock** of a deck. It shows whether Companion has locked the deck with its PIN.
- **Reconnect** of a deck. It turns the USB port off and on, for a deck that hangs.

**Find** and the **Speaker** media player exist only while **Speaker connected** is on in the web UI. They come and go by themselves when it changes. **Screen off after** is in minutes, 0 means never. **Screen saver brightness** is the level the decks dim to after that time. 0 turns them off.

The **Speaker** plays text to speech and audio files from the media browser. Home Assistant converts them with ffmpeg, so every format ffmpeg reads works. Sound is mono at 16 kHz. Web radio and Music Assistant work too and play until you stop them. A new clip or **Find** stops the one that plays.

The connector pushes every change at once. Signal and temperature update once a minute.

## Key presses

Keys, dials and the touch strip belong in [Companion](/docs/companion) or the [Elgato app](/docs/elgato-app). They draw the keys and run the action.

Home Assistant still gets every press, dial turn and touch. Each deck has a **Controls** event entity, and the automation editor offers them as device triggers. The event's `event_type` says what happened, for example `key_3_press`. A key that a source also uses runs both actions.

## Apple Home

The [HomeKit Bridge](https://www.home-assistant.io/integrations/homekit/) shows a deck as a set of buttons in the Home app. Open the options of the HomeKit Bridge in bridge mode and pick the deck under **Devices (Triggers)**. Each key press, dial press, dial turn and touch is one button.

## Good to know

- Home Assistant talks to the connector over plain HTTP on port 80.
- Presses from the live deck on the web page reach Home Assistant. Presses from a script reach it only with `"real": true`. Home Assistant never presses anything on the deck.
- After a firmware update the integration loads again by itself, so new entities appear.
- The logger is `custom_components.deckconnector`.

## Troubleshooting

Home Assistant shows problems it can fix under **Settings › Repairs**.

If all entities are unavailable, Home Assistant cannot reach the connector. Open the connector's address in a browser. If the address changed, use **Reconfigure**.

For a bug report, use **Download diagnostics** on the connector's device. It leaves out the key, addresses and serial numbers.
