## Im Browser

Der [Flasher](/de/flash/) schreibt das neueste stabile [Release](/de/docs/updates#releases). Er braucht Chrome oder Edge auf einem Computer.

<Ports lang="de" />

Nach dem Flashen kann der Flasher über dasselbe Kabel dein WLAN eintragen. Alles andere folgt in der [Einrichtung im Browser](/de/docs/first-setup).

Der Flasher schreibt nur den Hauptchip. Der WLAN-Chip bekommt seine Firmware als normales [Update](/de/docs/updates).

Etwas ging schief? Siehe [Probleme beim Flashen](/de/docs/flash-troubleshooting).

## Mit esptool

Nimm [esptool](https://docs.espressif.com/projects/esptool/) 5 oder neuer mit den Dateien aus einem [Release](/de/docs/updates#releases).

<Tabs items={['Neuinstallation', 'Update']}>
<Tab value="Neuinstallation">

```bash
esptool --chip esp32p4 -p /dev/ttyACM0 erase-flash
esptool --chip esp32p4 -p /dev/ttyACM0 -b 921600 write-flash 0x0 deckconnector-factory.bin
```

</Tab>
<Tab value="Update">

```bash
esptool --chip esp32p4 -p /dev/ttyACM0 -b 921600 write-flash 0xf000 ota_data_initial.bin 0x20000 deckconnector.bin
```

</Tab>
</Tabs>

Unter Windows heißt der Port `COM3` oder ähnlich, unter macOS `/dev/cu.*`.
