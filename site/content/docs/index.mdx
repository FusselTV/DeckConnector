DeckConnector is free firmware for a small board. The connector drives an [Elgato Stream Deck +](https://www.elgato.com/us/en/p/stream-deck-plus) over USB and puts it on your network. It works like an [Elgato Network Dock](https://www.elgato.com/us/en/p/network-dock-stream-deck), and adds Wi-Fi.

<Topology />

- [Bitfocus Companion](https://bitfocus.io/companion) connects over Satellite, or as a Network Dock.
- The [Elgato app](https://www.elgato.com/us/en/s/stream-deck-app) finds it as a Network Dock.
- [Your own server](/docs/own-server) draws the keys over WebSocket.
- Several programs connect at once. You [pick the source](/docs/hosts) that draws on the deck.
- [Home Assistant](/docs/home-assistant) gets every key press. [Matter](/docs/matter) adds Apple Home and Google Home.
- Wi-Fi and Ethernet at the same time. [When the cable fails](/docs/network), Wi-Fi takes over.
- [Signed updates](/docs/updates). A firmware that does not start rolls back by itself.

## What you need

- **Board.** A [Waveshare ESP32-P4-WIFI6-POE-ETH](https://www.waveshare.com/esp32-p4-wifi6-poe-eth.htm), see [Hardware](/docs/hardware).
- **Deck.** A Stream Deck + (tested). [Other models](/docs/hardware#decks) should work too.
- **Power.** A USB-C power supply, or a PoE switch port.
- **Computer.** Chrome or Edge, to [flash](/flash/) once.

## Try it first

The [demo](/demo/) runs the real web UI with a virtual deck in your browser. Nothing to install.
