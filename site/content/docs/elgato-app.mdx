---
title: Elgato app
description: The Elgato app (Stream Deck software) uses the connector as a Network Dock, over Wi-Fi or Ethernet.
---

The connector answers like an [Elgato Network Dock](https://www.elgato.com/us/en/p/network-dock-stream-deck) with the deck plugged in. The [Stream Deck app](https://www.elgato.com/us/en/s/stream-deck-app) on a computer in the same network finds it by itself.

If the deck does not show up, add it under **Settings › Devices › Add network deck** with the connector's address.

## Pairing

The connector remembers up to 8 computers that connected.

With **Paired sources only** on, the first computer still gets in. Every later one waits until you accept it on the deck or in the web UI ([demo](/demo/#sources)), or until you open pairing for 5 minutes.
