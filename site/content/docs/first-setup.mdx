## In the browser

The deck shows the connector's address and a QR code. Scan the code with a phone, or open `http://<address>/` on a computer in the same network. No address? The connector has no network yet. Join a Wi-Fi in the [flasher](/flash/), plug in a cable, or use the [setup Wi-Fi](#over-the-setup-wi-fi).

Every browser that opens the page goes straight into setup, so you can switch to a phone or a second computer. This works for 30 minutes after the connector starts, until someone sets a password or finishes setup. Later, scan the QR code on the deck instead. It logs you in.

The wizard asks for the name, your own password, the network and the source that controls the deck. The name is also the network name, for example `deckconnector-a1b2c3.local`. [Try the wizard in the demo](/demo/?setup).

## Over the setup Wi-Fi

Without a network, the connector opens its own Wi-Fi. This happens right after the start, or after one minute when a cable is plugged in. You can also start it in the deck menu under **Setup Wi-Fi**.

Scan the QR code on the deck with the phone camera. The phone joins and opens the page by itself. Without a QR scanner, join the network with the name and password the deck shows. If the page does not open, open any `http://` address, or the one on the deck.

The page only asks for your Wi-Fi. You finish setup on your own network.

## On the deck alone

The web UI is optional. Plug in a network cable and enter the address from the deck in the [Elgato app](/docs/elgato-app) or in [Companion](/docs/companion).

When Companion is in the network, the deck shows **Companion found**. Tap **Connect**.

On a deck with dials you can set a fixed LAN address in the deck menu under **LAN**. Turn a dial to change a number, press it for the next field, then tap **Save**.

## Factory reset

- In the deck menu, hold **Restart** for 5 seconds, then let go.
- Or pick **Reset** on the web login page and confirm twice on the deck.
- Or, logged in, pick **Reset** next to **Factory reset** under **Firmware** in the web page.

A reset removes every setting, the API keys, the paired sources, an uploaded certificate, an uploaded web page and the crash report. The new password shows on the deck, and setup starts again.
