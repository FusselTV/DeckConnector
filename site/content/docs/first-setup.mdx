## In the browser

Without a cable, set Wi-Fi in the [flasher](/flash/) or use the [setup Wi-Fi](#over-the-setup-wi-fi) first. With a network cable, the deck shows its address and a QR code. Scan the code with a phone, or open `http://<address>/` on a computer in the same network.

The first browser that opens the page within 30 minutes after the start goes straight into setup. Every later one scans the QR code, which logs a browser in once (each code for 10 minutes, until setup is done), or logs in as `admin` with the password from the [deck menu](/docs/getting-started#the-deck-menu).

The wizard asks for the language and name, your own password, the network, and the program that controls the deck. The name is also the network name, for example `deckconnector-a1b2c3.local`. [Try the wizard in the demo](/demo/?setup).

You can run it again later under **Firmware › Backup**.

## Over the setup Wi-Fi

Before setup is done, a board with no cable and no Wi-Fi from the flasher opens its own Wi-Fi right after the start. With a cable or a Wi-Fi that does not work, it waits one minute. You can also start it in the deck menu under **Setup-WLAN** (setup Wi-Fi).

Scan the QR code on the deck with the phone camera. The phone joins and opens the page by itself. If you closed it, open any `http://` address, or the one on the deck.

The page only asks for your Wi-Fi. Once the board is in, the setup Wi-Fi closes after 20 seconds, the phone goes back to your Wi-Fi, and you finish setup at the new address.

<Callout type="warn">
The board has 2.4 GHz Wi-Fi only.
</Callout>

## On the deck alone

The web UI is optional. Plug in a network cable and enter the address from the deck in the [Elgato app](/docs/elgato-app) or in [Companion](/docs/companion).

When Companion announces Satellite in the network, the deck asks **Companion gefunden, verbinden?** (Companion found, connect?). One key connects it.

On a deck with dials you can set a fixed LAN address in the deck menu under **LAN**. Turn a dial to change a number, press it for the next field, then tap **Speichern** (save).

## Factory reset

- In the deck menu, hold **Neustart** (restart) for 5 seconds, then let go.
- Or pick **Reset** on the web login page and confirm twice on the deck.
- Or, logged in with the password, pick **Reset** under **Firmware** in the web page.

A reset removes every setting, the API keys, the paired hosts, an uploaded certificate, an uploaded web page and the crash report. The new password shows on the deck, and setup starts again.
