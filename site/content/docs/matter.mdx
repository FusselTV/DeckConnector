---
title: Matter
description: Use the deck's keys in Apple Home, Google Home, Home Assistant and other Matter apps.
---

With Matter on, every deck shows up as a device in your smart home app. Each key, dial and touch zone is a button there. Each dial has two more buttons for turns, and the touch strip two for swipes. A press, a release and a long press can each start an automation. A press arrives at once. Companion or the Elgato app keeps working as before.

## Pair

1. Open **Sources › Matter** in the web UI and turn Matter on.
2. If no code shows, use **Start pairing**.
3. In your app, add a new device and scan the code. Or type the pairing code.
4. Your app says the device is not certified. That is correct. It uses the test vendor ID `0xFFF1`. Add it anyway.

**Show on the deck** puts the code on the deck. A key press hides it.

While the deck shows the menu or a question from the connector, its keys do not reach Matter.

## What you get

| Deck | Buttons |
|---|---|
| Stream Deck Mini | 6 |
| Stream Deck, MK.2 | 15 |
| Stream Deck XL | 32 |
| Stream Deck + | 8 keys, 4 dials, 8 turns, 4 touch zones, 2 swipes |
| Stream Deck + XL | 36 keys, 6 dials, 12 turns, 6 touch zones, 2 swipes |
| Stream Deck Neo | 8 keys, 2 touch points |
| Stream Deck Pedal | 3 |

Each deck is its own device. It keeps its buttons when you plug it in again, also at another hub port. An unplugged deck shows as not responding. A different deck in its place is a new device.

A dial turn presses "Dial 1 left" or "Dial 1 right" once per step. A fast turn sends at most 10 presses a second. A tap on the touch strip presses the zone under it. A long touch is a long press. Presses sent from the web UI or the API do not reach Matter.

## Home Assistant

Home Assistant names each button after its key, for example "Button (Key 1)" or "Button (Dial 2)". The part in brackets uses the deck's language. Home Assistant takes these names only from devices with the test vendor ID `0xFFF1`. The connector has that ID.

After an update or a new deck language, open the device in Home Assistant and use **Re-interview device**. Then reload the Matter integration to see the new names.

## Apple Home

Apple Home needs a home hub for Matter devices: a HomePod, HomePod mini or Apple TV. Without one, the deck pairs, but its buttons show "This accessory requires a home hub" and start nothing.

## Google Home

Google Home pairs only test devices that are added to your project in the [Google Home Developer Console](https://console.home.google.com/). Add vendor ID `0xFFF1` and product ID `0x8000`.

## Remove

**Reset Matter** removes the deck from every app and makes a new pairing code. Then delete the device in each app. Turning Matter off restarts the connector. The pairing stays for the next time you turn it on.
