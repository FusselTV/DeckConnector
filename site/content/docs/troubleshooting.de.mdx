## Die Deck-Bildschirme

| Auf dem Deck | Was hilft |
|---|---|
| ![Kein Netz](/docs/deck-st-no-network-de.webp) | Weder LAN noch WLAN hat eine Adresse. Kabel einstecken oder am Deck auf **WLAN** tippen, das startet das Setup-WLAN |
| ![Warte auf Companion](/docs/deck-st-companion-de.webp) | Companion ist die aktive Quelle, aber nicht verbunden. Siehe [unten](#companion-verbindet-sich-nicht) |
| ![Companion nicht erreichbar](/docs/deck-st-companion-away-de.webp) | Die Companion-Adresse antwortet nicht. Unter **Quellen** prüfen |
| ![Warte auf die Elgato App](/docs/deck-st-app-de.webp) | Siehe [unten](#die-elgato-app-findet-das-deck-nicht) |
| ![Suche Server](/docs/deck-st-server-de.webp) | Keine Server-Adresse gesetzt, und keiner meldet sich. Eine unter **Quellen** eintragen |
| ![Server getrennt](/docs/deck-st-server-off-de.webp) | Prüfen, ob der Server läuft und Adresse und Port stimmen |
| ![Verbindungsanfrage](/docs/deck-st-request-de.webp) | Ein unbekannter Rechner will das Deck. **Annehmen** lässt ihn rein, **Ablehnen** hält ihn draußen |
| ![Companion gefunden](/docs/deck-st-offer-de.webp) | **Verbinden** verbindet es über Satellite. **Nein** fragt nicht mehr |
| **Setup 2/5** auf einer Taste | Jemand ist in der Einrichtung im Browser. Dort beenden oder überspringen |

## Das Deck bleibt dunkel oder ist langsam

- Der Connector braucht Strom. Mit PoE muss der Switch-Port ihn liefern.
- Das Deck gehört in den **USB-A**-Port.
- **Neu verbinden** in der Weboberfläche schaltet seinen USB-Strom aus und wieder an.
- Ein dunkles Deck wacht mit einem Druck auf. Kommt das Dunkel vom Bildschirmschoner, vom Bildschirm-Schalter oder von Helligkeit 0, weckt dieser Druck es nur. Hat Companion oder die Elgato-App die Helligkeit auf 0 gesetzt, geht der Druck auch an sie.
- Hinter einem USB-Hub läuft das Deck oft nur mit Full Speed, Bilder kommen dann langsamer. Steck es direkt ein.

## Die Weboberfläche öffnet sich nicht

- Nimm die IP aus dem Deck-Menü statt des `.local`-Namens.
- Mit **Nur HTTPS** muss die Adresse mit `https://` beginnen.
- Nach einer Netzwerkänderung ändert sich die Adresse. Das Deck-Menü zeigt die neue.
- Nach zu vielen falschen Passwörtern wartet die Anmeldung bis zu einer Minute.
- [Passwort vergessen?](/de/docs/security#passwort-vergessen)

## Companion verbindet sich nicht

- In Companion muss **Settings › Satellite** an sein.
- Der Connector muss Companion auf TCP 16622 erreichen, oder 16623 für `ws://`. Für Docker siehe [Companion verbinden](/de/docs/companion).
- Unter **Quellen** prüft **Speichern** die Companion-Adresse zuerst und sagt, ob Companion antwortet.
- Das Deck erscheint doppelt? Ein Proxy verdeckt die Adresse von Companion. Entferne die Remote Surface in Companion.

## Die Elgato-App findet das Deck nicht

- Der Computer muss im selben Netz sein, nicht in einem Gast-WLAN.
- Eine Firewall auf dem Computer kann die App blockieren.
- Das Deck muss stecken, wenn die App startet. Sonst starte die App neu.
- Eine abgelehnte App fragt erst nach ihrem Neustart wieder.

## Ein Update bleibt nicht

Die neue Firmware kam nicht innerhalb von zwei Minuten ins Netz oder lief keine 20 Sekunden. Warum, steht unter **Log**. Schalte **Technisch** ein. Die Zeilen unter dem Neustart sind vom Start davor ([Demo](/de/demo/#log)).

## Logs und Absturzberichte

**Log** zeigt Ereignisse, Eingaben und das Roh-Log in einer Liste. Ereignisse bleiben über Neustarts und Stromausfälle erhalten. Das Roh-Log vom Start davor bleibt bis zu einem Stromausfall. **Diagnose** zeigt den letzten Absturzbericht. Ein Absturzbericht kann das Passwort enthalten, deshalb öffnet ihn nur das Passwort.

```bash
curl -u admin:PASSWORT http://192.168.1.50/api/log > log.txt
curl -u admin:PASSWORT 'http://192.168.1.50/api/log?boot=prev' > log-prev.txt
```
