Open the board's address in a browser and log in as `admin`. Each link below opens that page in the [demo](/demo/), the real web UI with a virtual deck.

| Page | What is there | More |
|---|---|---|
| [Overview](/demo/#overview) | **Active source**, the live deck, brightness, sounds, deck menu, reconnect, restart | [Multiple hosts](/docs/hosts) |
| [Sources](/demo/#sources) | Companion, Elgato app, own servers, certificate pins, pairing, Matter in the Matter firmware | [Companion](/docs/companion) |
| [Deck](/demo/#deck) | Attached decks, the menu keys and hold time, USB speed, screen off | [Hardware](/docs/hardware) |
| [Network](/demo/#network) | Name, LAN, Wi-Fi, where the board is reachable | [Network](/docs/network) |
| [Access](/demo/#access) | Password, login code, HTTPS, API keys, CORS | [Security](/docs/security) |
| [Firmware](/demo/#firmware) | Updates, slots, web page, backup, **Setup** | [Updates](/docs/updates) |
| [Diagnostics](/demo/#diagnose) | Log, events, inputs, counters, memory, crash report | [Troubleshooting](/docs/troubleshooting) |

The live deck is locked until you turn on **Remote control**. Its presses are real and go to the program that draws.
