Open the board's address in a browser and log in as `admin`.

The links below open the [demo](/demo/), the real web UI with a virtual deck.

## Overview

[Open in the demo](/demo/app/?lang=en#overview)

- **Active source** lists every connected program. Pick a row to hand the deck over.
- **Live deck** shows what the deck shows. Click, hold, swipe and turn it like the real one.
- Brightness, the deck menu, reconnecting the deck and a restart.

The live deck is locked until you turn on **Remote control**. Its presses are real and go to the program that draws.

## Sources

[Open in the demo](/demo/app/?lang=en#sources)

Companion, the Elgato App and your own servers. Add and remove them, pin certificates, and handle pairing. See [Companion](/docs/companion), [Elgato App](/docs/elgato-app) and [Own server](/docs/own-server).

## Deck

[Open in the demo](/demo/app/?lang=en#deck)

The attached decks, which keys or dials open the deck menu, how long to hold them, and the USB speed.

## Network

[Open in the demo](/demo/app/?lang=en#network)

Name, LAN, Wi-Fi and the addresses where the board can be reached. See [Network](/docs/network).

## Access

[Open in the demo](/demo/app/?lang=en#access)

Password, login code on the deck, HTTPS, certificate, API keys and CORS. See [Access and security](/docs/security).

## Firmware

[Open in the demo](/demo/app/?lang=en#firmware)

Updates, firmware slots, the uploaded web page, backup and restore, and **Run setup again**. See [Updates](/docs/updates).

## Diagnostics

[Open in the demo](/demo/app/?lang=en#diagnose)

Log, events, inputs, counters, memory, boot timing, the last crash report and the API routes. The log of the start before the last restart stays until a power cut.
